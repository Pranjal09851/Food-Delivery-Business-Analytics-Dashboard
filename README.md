# Food-Delivery-Business-Analytics-Dashboard

An end-to-end Power BI project that turns a real-world food delivery dataset into an interactive, multi-page business analytics report.

## 📌 Overview
This project covers the full analytics workflow: understanding the dataset, cleaning it with Power Query, building a star-schema data model, writing DAX measures, and designing dashboards that answer key business questions about orders, customers, restaurants and delivery.

## 🎯 Business Questions Answered
- How are revenue, orders and customers trending over time?
- What is the Average Order Value (AOV)?
- Who are the most valuable customers, and how do they behave?
- Which restaurants perform best?
- Where can delivery performance be improved?

## 🛠️ Tools & Skills
- **Power BI Desktop**
- **Power Query** (ETL, data cleaning, transformation)
- **DAX** (calculated columns and measures)
- **Data Modeling** (relationships, dimension and fact tables)

## 🗂️ Data Model
| Table | Description |
|-------|-------------|
| Orders | Fact table with order-level transactions |
| Customers | Customer details |
| Restaurants | Restaurant details |
| Date | Calendar table for time intelligence |

## 📊 Report Pages
1. **Introduction**: project overview and navigation
2. **ETL Process & Data Modeling**: cleaning steps and model diagram
3. **Calculated Columns & Measures (DAX)**: documentation of the logic
4. **Executive Overview Dashboard**: Revenue, Orders, Customers, AOV
5. **Customer Analytics Report**: customer segments and behavior
6. **Restaurant Performance Analysis**: top and bottom performers
7. **Delivery Insights**: advanced features and drillthrough

## 📈 Key Metrics (DAX)
- Total Revenue
- Total Orders
- Total Customers
- Average Order Value (AOV)

## ✨ Features
- Interactive slicers and filters
- Cross-visual highlighting
- Drillthrough for detailed analysis
- Clean, consistent design across pages
